# Winter Adventures

Зимняя ритм-игра с вертикальной картой из 12 уровней. Карта и точки масштабируются вместе. Тап по уровню сразу запускает 90-секундный тур «Утиные истории»; пока этот трек используется на всех уровнях.

Попадания дают очки и комбо. Звёзды начисляются за 40 / 65 / 85% пойманных нот. При получении звезды края экрана вспыхивают жёлтым. Нажатая нота пропорционально сжимается; на поддерживаемых устройствах срабатывает вибрация. Лучшие звёзды уровней и позиция персонажа сохраняются в браузере. После уровня 12 персонаж переходит к уровню 1.

## Локальный запуск

Нужны Python 3 и Node.js 22+ для сборки и проверок. Зависимостей приложения нет.

```sh
npm test
npm run build
npm run preview
```

Откройте http://127.0.0.1:8002/ — это та же сборка, которая публикуется. Карта находится на главной, игра — в `game.html`, UI-kit — в `ui-kit.html`.

Для редактирования исходников: `npm start`, затем http://127.0.0.1:8001/levels.html. Прямой запуск игрового меню: http://127.0.0.1:8001/index.html.

## Публикация

Push в `main` запускает проверки, сборку и публикацию в GitHub Pages:

https://forallprime-debug.github.io/winter_adventures/

В Settings → Pages должен быть выбран источник **GitHub Actions**. Инструкция подключения к Telegram: [TELEGRAM.md](TELEGRAM.md).

## Управление

Тапайте по одной из трёх дорожек, когда белая полоска ноты совпадает с линией в области нажатия. Длинные ноты удерживайте. На компьютере: C / B / M или стрелки влево / вниз / вправо. Пауза — кнопка, Escape или пробел. «На карту» доступно из паузы и результатов.

## Основные файлы

- `levels.html`, `levels.css`, `levels.js` — карта и прогресс.
- `forest-game.js`, `forest.css` — игра, ввод, очки, эффекты и результат.
- `telegram.js` — Telegram SDK, вибрация, безопасные отступы, возврат и пауза.
- `design/` — токены, компоненты и Canvas-отрисовка нот.
- `assets/` и `Music/duck-tales-90.m4a` — локальные ресурсы.
- `tools/build-site.js` — сборка в `_site/` с явным списком публикуемых файлов.

`npm test` проверяет актуальную игру, сборку и Telegram-интеграцию. Старый прототип с боссами оставлен в исходниках для истории; его проверки доступны отдельно через `npm run test:legacy` и требуют отсутствующих старых аудиофайлов. Он не включается в опубликованную сборку. Черновые генерации, референсы и исходные MP3 не загружаются в репозиторий.
